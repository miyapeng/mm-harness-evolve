# Development conventions

- Read README.md and docs/PROJECT.md first. PROJECT.md is the only current overview; update it at milestones. Keep dated literature, upstream licenses and immutable experiment reports separately.
- Research: Self-Evolving Multimodal Agent Harness. H_MM = H_generic + Pi_MM; Pi_MM = Acquire/Transform/Persist/Route/Ground/Verify executable runtime policies. No weight training in phase 1; same frozen A/B model revision, separate sessions.
- Keep B outer framework, A evolution target, benchmark/evaluator and model/provider/budgets separate. Execution-time A media control is distinct from evolution-time B evidence use. Scorer VLM is never A Verify.
- New proposals use mechanism-patch/v1: generic or multimodal_specific, primary/secondary MM stages and modalities. Apply the remove-media counterfactual. Old six categories are legacy tags only; never infer new scope from historical labels.
- Diagnose real events/media and check source before proposing a mechanism. Generic changes and no_change are valid. Never invent visual failures or infer a missing mechanism from a benchmark name. Prompt ordering is not a hard tool workflow.
- Preserve every historical run/frozen file and source identity; never migrate JSON in place. load_proposal returns a read-only legacy view with unknown scope. Use a fresh identity for changed protocol; do not overwrite stopped/interrupted workspaces.
- Model requests, artifact hashes, provenance, derived parents and freshness must be auditable. Collected != readable != passed != understood. Missing runtime instrumentation means trigger_unknown and count lower bounds, not zero behavior. Generic gains are not MM gains.
- Current active pool: swe_mm, gamedevbench, vision2web, osworld_verified, agentic_vbench, browsecomp_v3. Design2Code/Claw-Eval-MM are archived under archive/ with old Python imports preserved; default adapter creation rejects them. ChartMimic/VisualWebArena placeholder packages/configs were explicitly removed; do not silently restore them. Keep Claw assets and historical/frozen records in place.
- Read mechanism-profile.json for portfolio and integration status; profile.json is legacy adapter wiring. Planned/source_integrated does not mean rollout/scoring/evolution_validated. Inspect actual upstream source and pin archive/commit/license before integration claims.
- New mutation-boundary.json maps actual stages/source, generic files and fixed evaluator/answers/environment/model/provider. Empty mutable means not enabled. File/YAML guards are not proof of arbitrary Python semantics; retain fixed external budgets, permissions and audit.
- E raw evidence only enters B; V returns aggregates and T is frozen evaluation only. Do not evolve on official test. A public dataset file named train is not proof of independent development data. Preserve historical contamination and Design2Code negative engineering results truthfully.
- E4/V4, one candidate and current E-strict/V-nondecrease gates are provisional search policy, not theory. Do not invent new acceptance thresholds without discussion. Separate search/deployment/judge/grounder costs and retain unknowns.
- User stopped jobs on 2026-09-13; SWE real evolution rounds = 0. This refactor authorizes no GPU/model/ClusterX/benchmark rollout. Do not restart without subsequent user instruction. Use offline tests/fixtures and source inspection.
- Keep upstream source/data inside this repository with lock/provenance; do not change MultimodalCode. Do not commit secrets, bulk media or third-party archives. Preserve source license uncertainty.
- Use small Git milestones; test research-critical identity, media, proposal/boundary and resume invariants. Current RQ1 definition, RQ2 evidence-to-mechanism discovery, RQ3 heldout/transfer; future ablations remain plans, not results.
